# Atlas de Provincias

© 2026 **Adela Moreno Vega** y **Carlos Moreno Otto**. Todos los derechos reservados (ver [LICENSE](LICENSE)).

App para aprender las provincias de España, sus capitales y comunidades jugando con el mapa: explorar, repasar, practicar (dónde está, cuál es, capitales, gentilicios, siluetas) y retos (contrarreloj y duelo). Se puede instalar en el móvil y funciona sin conexión.

Se publica con GitHub Pages: https://indalo-apps.github.io/atlas-provincias/

Para sacar una versión nueva: subir el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js), y añadir sus novedades en `NOVEDADES`. Los móviles que la tengan abierta se actualizan solos, sin cortar una partida a medias.
